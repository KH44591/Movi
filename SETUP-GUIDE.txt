# MOVI — Google Sheets Setup Guide
# Customer order হলে auto Google Sheet এ যাবে

=============================================
STEP 1 — Google Sheet খোলো
=============================================

তোমার Sheet link:
https://docs.google.com/spreadsheets/d/1CXBKq01l8DtT94w3cYEEXVUUsKnfz_EQadXZMk2YJIM/edit

Sheet এ যাও।


=============================================
STEP 2 — Apps Script খোলো
=============================================

Google Sheet এ উপরে মেনু থেকে:
Extensions > Apps Script

একটা নতুন tab খুলবে — Script Editor।


=============================================
STEP 3 — Code paste করো
=============================================

Script Editor এ যা আছে সব DELETE করো।

তারপর "google-apps-script.js" ফাইলের
সব code copy করে paste করো।

Save করো (Ctrl+S বা Cmd+S)।
Project name দাও: "MOVI Orders"


=============================================
STEP 4 — Test করো (optional কিন্তু recommended)
=============================================

Script Editor এ উপরে dropdown থেকে
"testOrder" select করো।

তারপর ▶ Run বাটন চাপো।

Google permission চাইলে — Allow করো।

তোমার Sheet এ গিয়ে দেখো —
একটা test row add হয়েছে কিনা।
হলে সব ঠিক আছে।


=============================================
STEP 5 — Deploy করো (সবচেয়ে important)
=============================================

Script Editor এ উপরে:
Deploy > New deployment

এরপর:
- "Select type" এ ক্লিক করো → "Web app" বেছে নাও
- Description: "MOVI Order System"
- Execute as: "Me"
- Who has access: "Anyone"  ← এটা অবশ্যই "Anyone" দিতে হবে

Deploy বাটন চাপো।

Google আবার permission চাইবে → Allow করো।

একটা URL পাবে এরকম:
https://script.google.com/macros/s/AKfycby.../exec

এই URL টা copy করো — এটাই তোমার webhook URL।


=============================================
STEP 6 — Website এ URL বসাও
=============================================

preorder.html ফাইল open করো।

এই line টা খোঁজো:
const SCRIPT_URL = "YOUR_APPS_SCRIPT_URL_HERE";

"YOUR_APPS_SCRIPT_URL_HERE" এর জায়গায়
তোমার copy করা URL বসাও।

যেমন:
const SCRIPT_URL = "https://script.google.com/macros/s/AKfycby.../exec";

Save করো।
GitHub এ upload করো।


=============================================
DONE! এখন test করো
=============================================

তোমার website এ গিয়ে preorder form fill করো।
Submit করো।

তারপর Google Sheet দেখো —
নতুন row add হয়ে গেছে! ✓


=============================================
Sheet এ যা যা দেখবে
=============================================

Column A  — Timestamp (কখন order হলো)
Column B  — Order ID (MOVI-2025-0001)
Column C  — Full Name
Column D  — Phone
Column E  — Email
Column F  — Size (EU)
Column G  — Color
Column H  — Delivery Address
Column I  — Payment Method
Column J  — Drop (Drop 001)
Column K  — Price (3499)
Column L  — Status (Pending Payment)


=============================================
Order deliver করলে Status update করো
=============================================

Column L (Status) manually update করতে পারো:
- Pending Payment  (yellow) — default
- Payment Received (green)  — manually change করো
- Shipped          (blue)   — manually change করো
- Delivered        (gray)   — manually change করো


=============================================
কোনো সমস্যা হলে
=============================================

Script Editor > Executions এ গেলে
সব request এর log দেখতে পাবে।
Error হলে সেখানে দেখা যাবে।
